# Agent documentation

This directory holds the documents used to guide implementation agents.

- [`AGENTS.md`](AGENTS.md) contains the active project instructions and research-extension context rules.
- [`research-extension-implementation-plan.md`](research-extension-implementation-plan.md) is the authoritative implementation plan for current research work.
- [`research-pivot-findings.md`](research-pivot-findings.md) and [`research-feasibility-rating-and-local-llm.md`](research-feasibility-rating-and-local-llm.md) are decision references.
- [`CHATBOT_IMPLEMENTATION_PLAN.md`](CHATBOT_IMPLEMENTATION_PLAN.md) is the chatbot implementation plan.
- [`DEPLOYMENT.md`](DEPLOYMENT.md) documents the implementation and operational deployment procedure.
- [`legacy/`](legacy/) contains completed-rebuild records. Do not use them to determine the current phase unless the active instructions explicitly call for them.

The root [`AGENTS.md`](../AGENTS.md) remains only as a conventional discovery bootstrap for coding-agent tools.
